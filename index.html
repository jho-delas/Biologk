Sobre Nós

Este é o Diário de Insetos, um projeto educacional para catalogar e etiquetar insetos seguindo normas entomológicas. Desenvolvido para atividade avaliativa para obtenção de notas na disciplina de Biologia, permitindo adicionar insetos com etiquetas de procedência e identificação, simulando uma coleção real. Use com responsabilidade e consulte um especialista para coletas reais. Projeto criado pelo grupo Twinxs do IF em 2025.
